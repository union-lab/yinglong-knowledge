**Q:抖店商家后台系统准入标准是什么，提交哪些信息是必须的？**

**A：要求规范如下：**

**自研对接必须提供具备自研能力相关资质，如不符合请引导你们服务商/开发商入驻服务商相关类目，详见：**[https://op.jinritemai.com/docs/guide-docs/231/1999](https://op.jinritemai.com/docs/guide-docs/231/1999)

| **提交内容** | **是否必填** | **规则说明** | **不支持的辅助材料/注意事项** |
| --- | --- | --- | --- |
| 企业主体要求 | 是 | 1. 店铺企业主体和开发者主体**必须一致**或**有控股、投资关系且公开可查**<br>2. **软著主体必须和开发者主体一致** | 1. 不支持A企业授权B企业授权书<br>2. 不支持员工在职证明等文件证明<br>3. 不支持家庭成员户口证明<br>4. 其他辅助材料均不支持 |
| 软件著作权证书要求 | 是 | 1. 必须提供由国家版权局颁发的软件著作权证书扫描件或照片，著作权人需与您店铺&开发者实名认证一致，且能够在中国版权保护中心官网（http://www.ccopyright.com.cn/）查询到有效信息<br>2. 软著必须电商相关如ERP、wms、CRM，等管理系统<br>3. 著作权人和登记号和软著图片信息匹配 | 1. 不支持非国家版权局颁发的软件著作权证书以外的版权认证，如易版权等<br>2. 不支持A企业授权B企业授权书<br>3. 不支持APP相关，如xx游戏、xx天气等非管理系统软著<br>4. 请认真填写内容，请勿存在PS或造假 |
| 系统功能说明书 | 是 | 1. 务必按照，信息不全将会驳回，系统功能说明书模板进行地址：https://bytedance.feishu.cn/docs/doccnGiV8CtR61IKeybAGfsQALc | 1. 无内容或内容不按规范填写 |
| 商家研发系统支出证明 | 是 | 1. 提供采购服务器资源等费用截图或合同文件等 | 无 |
| 绑定店铺shop_id | 是 | 1. 提供经营中的店铺ID | 1. 即时零售店铺请勿申请，即时零售店铺申请即时零售自研类目 |
| 对接业务方向 | 是 | 1. 简述要对接的业务和场景 | 无 |
| 登录界面和功能界面截图 | 是 | 1. 您的系统登录界面的截图和系统主要功能截图，必须提供全景截图，切勿使用小图 | 1. 请认真填写内容，请勿存在PS或造假 |
| 备注说明 | 否 | 按需填写 | 无 |

**Q:易版权的电子版权认证证书是否可用作软著？**

**A：**不可以，必须提供由**国家版权局颁发的软件著作权证书**扫描件或照片，著作权人需与您店铺&开发者实名认证一致，且能够在中国版权保护中心官网（[http://www.ccopyright.com.cn/](http://www.ccopyright.com.cn/)）查询到有效信息。其他软著认证平台均不符合要求。

**Q:自研应用没有软著证书是否可以创建应用？**

**A：**不可以，这个是必须提供的内容，请看上方规则说明

**Q:申请商家后台系统需要提供软著/系统代码相关，但无法提供，如何解决？**

**A：**自研对接必须提供具备自研能力相关资质，如不符合，可以选择引导服务商入驻或在服务市场订购。①请引导你们服务商/开发商入驻服务商相关类目，详见：[https://op.jinritemai.com/docs/guide-docs/231/1999](https://op.jinritemai.com/docs/guide-docs/231/1999) ②也可以选择直接订购服务市场相关服务：[点击前往](https://fuwu.jinritemai.com/?btm_pre=a0254.b9825.c8589&page_from=1iffbkf3o_b9825&pre_show_id=1caa99c5-63c4-4bac-a779-e94588a99cc5)

**Q:提交申请都被驳回了，不符合自研商家入驻要求，如何解决？**

**A：**①请引导你们服务商/开发商入驻服务商相关类目，详见：[https://op.jinritemai.com/docs/guide-docs/231/1999](https://op.jinritemai.com/docs/guide-docs/231/1999) ②也可以选择直接订购服务市场相关服务：[点击前往](https://fuwu.jinritemai.com/?btm_pre=a0254.b9825.c8589&page_from=1iffbkf3o_b9825&pre_show_id=1caa99c5-63c4-4bac-a779-e94588a99cc5)

**Q:我有其他企业和商家的授权书是否可以？**

**A：**不可以，不支持非平台额外要求外的不支持的辅助材料，详见上方“企业主体要求”和“软件著作权证书要求”
