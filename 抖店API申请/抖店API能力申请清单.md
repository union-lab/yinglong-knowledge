# 抖店 API 能力申请清单（商家自研申请版）

> 适用对象：抖店开放平台“商家后台系统”自用型应用  
> 官方目录：<https://op.jinritemai.com/docs/api-docs/162/6060>  
> 具体接口归档：[`具体接口文档/README.md`](./具体接口文档/README.md)（16 类、506 个接口）  
> 收费规则：[`抖店API收费规则.md`](./抖店API收费规则.md)  
> 复核日期：2026-07-14  
> 使用原则：14 类 API 必须申请；短信 API 不申请；工具 API 原则上不作为业务权限申请。

## 一、申请结论

1. **核心业务 API：9 类必须申请。** 包括店铺、素材中心、商品、订单、库存、售后退款、物流发货、电子面单、账单。
2. **专项业务 API：5 类必须申请。** 包括精选联盟、保险、商户登录风险、飞鸽、短视频。
3. **短信 API：不申请。** 不纳入本次应用能力范围，也不在申请材料中作为业务功能描述。
4. **工具 API：原则上不申请。** `/token/create`、`/token/refresh`、`/open/getAuthInfo` 等授权、鉴权或接入必需能力按平台要求保留，不等于申请整包工具 API。
5. **其他专项 API：不纳入本次申请。** 电商小程序、代发、跨境、三方客服、即时零售等未被列为必须申请的专项能力，仍按明确业务需求单独评估。
6. **收费按接口级名单核算。** 申请范围和收费范围是两个维度，不能仅按左侧 API 目录判断是否收费。

## 三、明确不申请的短信 API

短信 API 当前目录可见 42 个接口，本次明确不申请。接口文档仍保留作范围核对和后续变更参考，见 [`具体接口文档/11_短信API.md`](./具体接口文档/11_短信API.md)。

- 申请权限时不勾选短信 API。
- 申请说明、功能说明书和系统截图中不把短信能力列为本次对接功能。
- 后续如确有短信业务需求，应重新确认用途、合规要求和费用后再调整申请范围。

## 四、原则上不申请的工具 API

工具 API 当前目录可见 12 个接口，具体清单见 [`具体接口文档/01_工具API.md`](./具体接口文档/01_工具API.md)。它是官方目录分类，不等同于收费规则中的“增值 API”。

| 处理方式 | 适用内容 | 判断标准 |
|---|---|---|
| 不主动申请 | 权益扣减/查询、服务市场权益、盲盒回传等 | 与友联自研 OMS/ERP 业务闭环无直接关系 |
| 接入时保留 | Token 创建/刷新、授权信息查询、素材上传 Token 等 | 业务 API 调用或授权鉴权确有技术依赖 |
| 单独评估 | 安全事件上报、OpenID 转换等 | 出现明确场景、平台强制要求或合规要求后再申请 |

> 边界：这里的“原则上不申请”是指不把工具 API 作为业务权限包整包申请，不是禁止使用接入所必需的鉴权接口。

## 五、其他专项 API 的处理

电商小程序、代发、跨境、卡券、三方客服、即时零售、营销管理等未列入上述 14 类必申请范围的专项 API，不纳入本次申请。

- 有明确项目需求、数据用途和负责人后，再补专项申请。
- 申请材料中不要为了“以后可能用”而扩大其他权限范围。
- 客服、达人、即时零售等场景应分别核对对应类目资质、授权方式和数据合规要求。

## 六、收费口径与预算边界

官方收费规则把收费 API 分为基础 API 和增值 API，并按抖店云内/云外调用分别定价。当前收费明细列出 17 个接口，全部标记为基础 API，分布在商品、订单、售后退款、账单、物流发货、素材中心 6 个目录分类中。

- 基础 API：云内 0.018 元/百次/Appkey；云外 0.18 元/百次/Appkey。
- 增值 API：云内 0.05 元/百次/Appkey；云外 0.5 元/百次/Appkey，未经允许禁止云外调用。
- 收费明细、结算规则和欠费处置见 [`抖店API收费规则.md`](./抖店API收费规则.md)。
- 需要申请不代表该目录下所有接口都收费，当前未收费也不代表永久免费。

## 七、申请材料建议写法

**对接业务方向：**

> 友联自研商家后台系统用于自有抖店的店铺与素材管理、商品管理、订单与库存同步、售后退款、物流发货、电子面单、账单对账，并对接精选联盟、保险保单、商户登录风险检查、飞鸽客服和短视频管理能力。本次申请上述 14 类 API；短信 API 不申请；工具 API 不作为业务权限整包申请，仅按平台接入要求使用必要的授权与 Token 能力。系统将按平台收费规则预充值并承担实际 API 调用产生的技术服务费。

**提交前核对：**

- [ ] 14 类必申请 API 均已勾选或写入权限申请说明
- [ ] 短信 API 未勾选，申请材料未把短信列为本次功能
- [ ] 精选联盟、保险、商户登录风险、飞鸽、短视频均已列为必申请
- [ ] 工具 API 未作为业务能力整包申请
- [ ] Token、授权查询等必要接入能力未被误删
- [ ] 功能说明书中的系统模块与申请权限逐项对应
- [ ] 每项权限都有真实功能、页面或调用场景支撑

## 八、证据与状态

- 官方“风控安全 API”目录当前仅有 `/antispam/userLogin`，即商户登录风险检查接口。
- 已将本次核对涉及的 16 类目录、506 个当前可见接口逐项保存为本地 Markdown，并保留官方明细接口的原始 JSON；总索引见 [`具体接口文档/README.md`](./具体接口文档/README.md)。

- 官方收费规则另行使用“免费 API / 收费 API / 基础 API / 增值 API”口径，应以具体接口收费名单为准。
- 平台接口、权限包和审核规则可能调整，正式提交前应再次以开放平台控制台实际可申请项为准。
