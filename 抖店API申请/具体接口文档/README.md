## 使用说明

- 每个接口均有独立 Markdown，包含接口元数据、说明、权限包、请求参数、响应参数、示例和错误码。
- `_原始JSON/` 保存官方明细接口的原始返回，作为无损复核材料。
- 本归档反映归档日官方目录当前可见状态；正式申请和开发前仍应复核在线文档。
- 友联申请口径：短信 API 不申请；工具 API 原则上不申请，Token、授权查询等接入必需能力除外；其余归档类别均为必申请。
