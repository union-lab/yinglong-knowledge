# 抖店 API 收费规则

> 适用对象：调用抖店开放平台 API 的开发者，包括服务商和商家自研应用  
> 收费接口明细：<https://op.jinritemai.com/docs/guide-docs/84/7277?hasActivateBot=1&hasUseBot=1>  
> 技术服务费规则：<https://op.jinritemai.com/docs/guide-docs/1281/3393>  
> 官方规则版本：V1.3，更新时间 2026-06-16  
> 复核日期：2026-07-14

## 一、老板版结论

1. **基础 API 也收费，不是只有增值 API 收费。** 官方先把 API 分为免费 API、收费 API，再把收费 API 分为基础 API、增值 API。
2. **收费对象包含商家自研应用。** “电商商家自研 -> 商家后台系统 -> 自用型”已列入收费应用类目。
3. **抖店云内调用成本明显更低。** 基础 API 云内价格是云外的 1/10，增值 API 云内价格也是云外的 1/10。
4. **增值 API 原则上只能在抖店云内调用。** 未经开放平台允许，禁止在抖店云外调用。
5. **收费按接口级名单执行。** API 文档左侧的“工具 API、商品 API、订单 API”等是目录分类；收费规则中的“基础 API、增值 API”是收费类型，两者不是同一个维度。
6. **当前收费明细列出 17 个接口，全部标记为基础 API。** 未出现在当前收费名单中的接口，不应据此认定永久免费，正式上线前仍需复核最新名单。
7. **采用预充值模式。** 已支付账单不退款，账户余额不可提现或转账；每月 5 日统计并扣除上一个自然月费用。
8. **欠费会影响全部接口和店铺授权。** 自用型应用欠费后会冻结自研应用和商家授权，并逐步限流直至全部应用接口停用。

## 二、收费标准

| 收费类型 | 调用来源 | 收费标准 | 折算单次成本 | 计费方式 |
|---|---|---:|---:|---|
| 基础 API | 抖店云内调用 | 0.018 元/百次/Appkey | 0.00018 元/次 | 按实际调用量计费 |
| 基础 API | 抖店云外调用 | 0.18 元/百次/Appkey | 0.0018 元/次 | 按实际调用量计费 |
| 增值 API | 抖店云内调用 | 0.05 元/百次/Appkey | 0.0005 元/次 | 按实际调用量计费 |
| 增值 API | 抖店云外调用 | 0.5 元/百次/Appkey | 0.005 元/次 | 按实际调用量计费；未经允许禁止云外调用 |

### 预算测算公式

```text
月技术服务费 = Σ（各收费接口当月实际调用次数 ÷ 100 × 对应百次单价）
```

计费以 `Appkey` 和实际调用量为基础。预算时应分别统计抖店云内、抖店云外调用量，不能混用单价。

## 四、结算与支付规则

- 采用预充值模式，开发者须提前充值账户余额。
- 已支付账单不支持退款。
- 账户余额不支持提现或转账。
- 平台每月 5 日统计上一个自然月的技术服务费，并从账户余额中扣除。
- 已实际支付的技术服务费可申请开具发票。
- 优质应用或服务可能享受优惠减免，具体按官方优惠规则执行。

## 五、欠费处理规则

| 欠费时长 | 处理措施 |
|---|---|
| 第 1 天、第 5 天 | 通知告警 |
| 第 10 天起 | 自用型应用冻结自研应用和商家授权；处置接口范围涉及全量 API，缴清后恢复 |
| 第 15 天起 | 欠费应用接口限流 20% |
| 第 20 天起 | 欠费应用接口限流 50% |
| 第 25 天起 | 账号下所有应用接口限流 100%，数据推送停止 |

- 缴清全部欠费后，平台解除相应处理措施。
- 因欠费处置给商家造成的损失，由开发者承担。
- 欠费超过一个月，平台可从服务市场保证金或商家保证金中划扣技术服务费。

## 六、对申请和技术方案的影响

1. 友联当前 14 类必申请 API 的范围保持不变，短信 API 不申请；申请时必须同时做调用量和费用预算。
2. 技术部署应优先评估抖店云，不能只按服务器价格比较，还要把 API 调用费差额纳入总成本。
3. 生产系统必须增加余额监控、费用预警和欠费保护，避免授权被冻结或接口被限流。
4. 对高频订单、商品、售后同步接口，应按“调用次数 × 调用来源单价”单独测算月成本。
5. 正式上线前再次复核收费接口名单、收费类型和优惠政策，平台更新后同步调整预算。

## 七、口径边界

- **API 目录分类**：工具 API、商品 API、订单 API、库存 API 等，用于按业务能力组织接口文档。
- **官方收费类型**：免费 API、收费 API；收费 API 再分基础 API、增值 API。
- **友联申请口径**：14 类 API 必须申请，短信 API 不申请，工具 API 原则上不作为业务权限整包申请。

三套口径需要同时保留，不能把“工具 API”直接替换成“增值 API”，也不能把“友联必申请”理解成对应目录下所有接口都一定收费。
