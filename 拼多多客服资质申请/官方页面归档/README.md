# 拼多多软件服务商上线审核页面归档

## 归档范围

本目录保存两份拼多多官方静态页面及页面引用的配图：

1. [469：提交服务上线审核前须知](./469_提交服务上线审核前须知.md)
2. [467：提交应用上线审核前须知](./467_提交应用上线审核前须知.md)

原始 HTML 位于 `原始页面/`，页面内图片位于 `图片/`。页面正文来自 2026 年 7 月 23 日实际下载的官方页面；后续提交前仍应以拼多多控制台和官方页面最新版本为准。

## 两份页面的区别

| 页面 | 适用重点 | 额外要求 |
|---|---|---|
| 469 | 服务上线审核，偏服务市场商品详情页 | 服务描述、版本排序、免费试用、最低价格、服务名称、图标和客服联系方式 |
| 467 | 应用上线审核，偏第三方开发者应用 | 第三方开发者文档、应用功能可用性、授权回调和店铺绑定 |

## 对友联申请的共同约束

- 软件功能必须真实、完整、可用，并与申请类目一致。
- 禁止导出拼多多订单数据到外部文件、采集拼多多商品信息、搬家拼多多商品。
- 禁止登录店铺后台、内嵌页面授权，或要求店铺账号密码登录。
- 禁止爬取平台未通过接口提供的数据，例如店铺后台数据中心数据。
- 不得提供服务市场中不存在的版本。
- 授权至少要覆盖两个场景：服务市场进入后的授权，以及软件内店铺绑定授权。

## 友联提交时的直接注意点

- 申请材料和服务详情只描述友联系统真实拥有的商品、订单、库存、售后、物流、账单、客服和运营能力。
- 不在标题、描述、详情页、图片和源码中出现其他电商平台、竞品、站外引流、微信公众二维码或非法功能描述。
- 不把“店铺后台登录”写成产品功能；使用拼多多开放平台授权回调完成店铺绑定。
- 如果走服务上线审核，服务版本应按周期从短到长排列，提供 7 天免费版本，并核对类目最低价格。
- 469 页面明确规定服务名称不得包含拼多多官方品牌名称，包括“多多”“拼多多”；服务图标不得使用拼多多官方 Logo。
- 页面只规定可以使用 QQ、座机、手机作为客服联系方式，同时禁止出现旺旺、微信等竞对联系方式。
