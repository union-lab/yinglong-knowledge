> 本费用是淘宝开放平台API、数据同步及相关技术服务的使用费，不是服务市场保证金，也不是应用销售收入的软件服务费分成。

## 二、收费对象

API收费对象为所有调用淘宝开放平台API的开发者，包括但不限于：

- 软件服务商ISV；
- 商家自研应用；
- 其他获得相应API调用资格的开发者。

平台将API分为免费API和收费API。具体某个接口属于哪一类，以该接口当期API文档标识为准。

## 三、TOP API收费标准

| API业务类型 | 聚石塔内调用 | 聚石塔外调用 | 计费方式 |
|---|---:|---:|---|
| 开放平台基础API | 0.02元/百次/AppKey | 0.20元/百次/AppKey | 按实际调用量 |
| 开放平台增值API | 0.06元/百次/AppKey | 0.60元/百次/AppKey | 按实际调用量 |
| 物流流转信息查询-菜鸟接口 | 0.02元/百次/AppKey | 0.20元/百次/AppKey | 按实际调用量 |
| 物流异常-菜鸟接口 | 0.10元/百次/AppKey | 0.50元/百次/AppKey | 按实际调用量 |

增值API未经平台允许，禁止在聚石塔外调用。

### 塔内与塔外成本差异

- 基础API：塔外价格是塔内的10倍；
- 增值API：塔外价格是塔内的10倍；
- 物流流转查询：塔外价格是塔内的10倍；
- 物流异常接口：塔外价格是塔内的5倍。

因此，对需要大量调用订单、商品、库存等接口的ERP应用，部署位置会直接影响API成本及接口使用资格。

## 四、API每日优惠政策

自2022年5月1日起，平台对每个AppKey每天调用“开放平台基础API”和“开放平台增值API”产生的费用，提供最高50元减免：

- 通过优惠券自动抵扣；
- 当日费用不足50元时，按实际费用等额抵扣；
- 当日未用完的优惠额度作废；
- 不能累计、提现或退款；
- 基础API和增值API费用合并占用该AppKey的每日优惠额度。

### 单一接口情况下的理论免付调用量

以下仅用于预算理解，实际以混合调用及平台账单为准：

| 调用类型 | 50元约可覆盖的调用次数/日 |
|---|---:|
| 塔内基础API | 250,000次 |
| 塔外基础API | 25,000次 |
| 塔内增值API | 约83,333次 |
| 塔外增值API | 约8,333次 |

计算示例：

```text
塔内基础API单次成本 = 0.02元 ÷ 100 = 0.0002元
50元 ÷ 0.0002元/次 = 250,000次
```

> 上表不代表平台承诺免费调用次数。如果一个AppKey同时调用多种API，应先按各自单价计算费用，再共同抵扣每日50元优惠。

## 五、数据同步服务收费

### 基础计费

- 按每个应用每日新增订单量计费；
- 官方基础标准：0.12元/百单；
- 每日新增订单量包括新推送用户的历史订单量，以及全部推送用户的当日新增订单量；
- 只统计淘宝/天猫交易主订单；
- 商品、分销、经销、退款等同步业务不计入该订单量计费；
- 父子订单只统计新增主订单。

### 套餐服务费

| 规格 | 订单量费用 | 套餐服务费 |
|---|---|---:|
| 基础版 | 按每日新增订单量 | 无额外套餐费 |
| 独享-高级版 | 按每日新增订单量 | 79元/天 |
| 独享-铂金版 | 按每日新增订单量 | 149元/天 |
| 独享-旗舰版 | 按每日新增订单量 | 299元/天 |

当日使用多个规格时，按照当日最高套餐规格收费。

### 订单量阶梯优惠

官方页面同时列明数据同步服务的阶梯优惠：

| 每日新增订单区间 | 优惠价 |
|---|---:|
| 1,000,000单以下（含） | 0.10元/百单 |
| 超出1,000,000单部分 | 0.04元/百单 |

超过100万单时采用分段计算：

```text
每日费用
= 1,000,000 × 0.10元/百单
+ 超出1,000,000单部分 × 0.04元/百单
```

## 六、其他相关技术服务收费

### 瓦力旺旺消息

- 旺旺聊天消息服务；
- 旺旺聊天系统消息服务；
- 0.01元/百条；
- 按每个应用每日新增聊天消息量计费。

### CRM产品服务

- 适用于CRM服务商独立版（C版）；
- 每万用户关系数0.06元/天。

### 淘宝开放平台MCP服务

| MCP类型 | 收费标准 |
|---|---:|
| 基础MCP | 0.02元/百次/AppKey |
| 增值MCP | 0.06元/百次/AppKey |
| 客服MCP | 0.03元/百次/AppKey |
| 质检MCP | 0.012元/百次/AppKey |

模型服务则按实际消耗的Token计费，不同模型的输入、思考和输出价格不同，须以当期模型价目表为准。

## 七、支付与结算

平台支持两种支付方式：

1. 预充值：开发者提前向技术服务费账户充值；
2. 支付宝代扣：签署支付宝代扣协议后，按实际消耗自动扣费。

计费触发后按日结算和扣费。费用中心路径：

```text
淘宝开放平台控制台
→ 财务
→ 费用中心
→ 技术服务费
→ 当前账户余额
```

欠费可能影响API或相关服务的正常使用，具体按平台公示的技术服务费欠费处理规则执行。

## 八、与其他费用的关系

| 费用类型 | 作用 | 是否为本文件范围 |
|---|---|---|
| 类目保证金 | 服务商履约与违规风险担保 | 否 |
| 服务市场软件销售分成 | 淘宝按应用销售收入收取软件服务费 | 否 |
| TOP API调用费 | 调用淘宝开放平台收费API | 是 |
| 数据同步服务费 | 实时同步订单等数据 | 是 |
| 奇门接口费 | 当前官方说明为免费开放 | 否 |
| 聚石塔/阿里云资源费 | ECS、SAE、RDS、Redis、带宽等 | 否 |

### 费用不能互相替代

- 缴纳企业ERP保证金，不会免除API调用费；
- 支付服务市场销售分成，不会自动免除数据同步服务费；
- 奇门接口免费，不代表TOP API、聚石塔服务器和数据库免费；
- 聚石塔内调用单价更低，但仍需承担聚石塔/阿里云资源成本。

## 九、友联ERP预算口径

ERP应用的淘宝平台成本至少应分开测算：

```text
总平台相关成本
= 类目保证金资金占用
+ 服务市场销售收入软件服务费
+ TOP API调用费
+ 数据同步服务费
+ 聚石塔/阿里云资源费
+ 其他消息、CRM、MCP或模型服务费
```

申请前应根据以下参数制作月度测算：

- 预计接入商家数；
- 每个商家日均订单量；
- 每单平均API调用次数；
- 基础API与增值API占比；
- 塔内与塔外调用比例；
- 每日新增同步订单量；
- 数据同步套餐规格；
- 旺旺消息、MCP和模型调用量；
- 每个AppKey每日50元优惠的实际覆盖情况。
