# 友联淘系接口清单（按权限包 ID）

> **数据来源**：淘宝开放平台控制台 → 类目开放能力 → 各权限包【详情】
> **抓取日期**：2026-06-26
> **适用应用**：商家后台系统（一站式电商后台 / 自研 OMS/ERP）
> **API 文档来源**：`https://open.alitrip.com/docs/api.htm?scopeId={权限包ID}&apiId={API_ID}`

## 使用方式

1. 在控制台「类目开放能力」找到权限包 ID。
2. 打开下表对应 **详情文件**，查看包内全部 API 及官方文档摘要（中文名、参数、错误码）。
3. 点击每个 API 的**官方文档链接**可跳转平台完整页面。

## 控制台「详情」与本文档的对应关系

| 控制台操作 | 本文档位置 | 平台公开 URL |
|---|---|---|
| 类目开放能力 → 权限包列表 | [权限包索引](#权限包索引) | 控制台内嵌 |
| 点击某包【详情】→ API 列表 | `permissions/{ID}-{名称}.md` | `api_list.htm?scopeId={ID}` |
| 点击某 API 文档 | 各 API 小节内的「官方文档」链接 | `api.htm?scopeId={ID}&apiId={apiId}` |
