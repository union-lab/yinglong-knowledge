#### `taobao.tmc.user.get`

**中文名**：获取商家所在分组及其已授权(广播)消息topics

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12159&apiId=22554)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `fields` | String | 必须 | user_nick,topics,user_id,is_valid,created,modified | 需返回的字段列表，多个字段以半角逗号分隔。可选值：TmcUser结构体中的所有字段，一定要返回topic。 |
| `nick` | String | 必须 | testnick | 用户昵称 |
| `user_platform` | String | 可选 | tbUIC | 用户所属的平台类型，tbUIC:淘宝用户; icbu: icbu用户;ae:ae用户 |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.invalid-param: usernick-empty` | 参数nick未传 | 传入相应参数 |
| `isv.tmc-switch-off: appkey` | 应用未开通消息服务 | 应用开通消息服务 |
| `isv.invalid-param: nick-error` | nick错误或与user_platform不匹配 | 请传入正确的userNick与user_platform |

#### `taobao.tmc.group.add`

**中文名**：为已开通用户添加用户分组

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12159&apiId=21983)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `group_name` | String | 必须 | vip_user | 分组名称，同一个应用下需要保证唯一性，最长32个字符。添加分组后，消息通道会为用户的消息分配独立分组，但之前的消息还是存储于默认分组中。不能以default开头，default开头为系统默认组。 |
| `nicks` | String [] | 必须 | lzgary001,lazgary002 | 用户昵称列表，以半角逗号分隔，支持子账号，支持增量添加用户 |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.invalid-param: invalid-group-name` | group_name的格式不正确 | group_name不能用default开头 |
| `isv.invalid-param: nick-error` | 用户昵称不正确 | 主输入正确的用户昵称 |
| `isp.system-error: TIMServiceException` | 服务端错误 | 重试 |

#### `taobao.tmc.user.permit`

**中文名**：为已授权的用户开通消息服务

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12159&apiId=21990)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `topics` | String [] | 可选 | taobao_trade_TradeCreate,taobao_refund_RefundCreate | 消息主题列表，用半角逗号分隔。当用户订阅的topic是应用订阅的子集时才需要设置，不设置表示继承应用所订阅的所有topic，一般情况建议不要设置。 |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isp.system-error: TIMServiceException` | 消息服务内部错误 | 重试 |
| `isv.need-subscribe: subscribe-topic-first` | 应用没有订阅指定的topic，无法给用户开通 | 请先订阅指定的topic |
| `isv.invalid-param: topic-empty` | 应用没有订阅任何topic | 请到TOP控制台为应用订阅至少一个topic |

#### `taobao.tmc.message.produce`

**中文名**：发布单条消息

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12159&apiId=21987)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `content` | String | 必须 | {"tid":2895732958732,"seller_nick":"helloworld"} | 消息内容的JSON表述，必须按照topic的定义来填充 |
| `target_group` | String | 可选 | default | 目标分组，一般为default |
| `topic` | String | 必须 | taobao_trade_TradeCreate | 消息类型 |
| `media_content` | byte[] | 可选 | 1010101 | 回传的文件内容，目前仅支持jpg,png,bmp,gif,pdf类型的文件，文件最大1M。只有消息中有byte[]类型的数据时，才需要传此字段; 否则不需要传此字段。 |
| `media_content2` | byte[] | 可选 | 1010101 | 回传的文件内容，目前仅支持jpg,png,bmp,gif,pdf类型的文件，文件最大1M。只有消息中有byte[]类型的数据时，才需要传此字段; 否则不需要传此字段。具体对应到沙体中的什么值，请参考消息字段说明。 |
| `media_content3` | byte[] | 可选 | 1010101 | 回传的文件内容，目前仅支持jpg,png,bmp,gif,pdf类型的文件，文件最大1M。只有消息中有byte[]类型的数据时，才需要传此字段; 否则不需要传此字段。具体对应到沙体中的什么值，请参考消息字段说明。 |
| `media_content5` | byte[] | 可选 | 1010101 | 回传的文件内容，目前仅支持jpg,png,bmp,gif,pdf类型的文件，文件最大1M。只有消息中有byte[]类型的数据时，才需要传此字段; 否则不需要传此字段。具体对应到沙体中的什么值，请参考消息字段说明。 |
| `media_content4` | byte[] | 可选 | 1010101 | 回传的文件内容，目前仅支持jpg,png,bmp,gif,pdf类型的文件，文件最大1M。只有消息中有byte[]类型的数据时，才需要传此字段; 否则不需要传此字段。具体对应到沙体中的什么值，请参考消息字段说明。 |
| `delay_millis` | Number | 可选 | 19832832833828 | 延时参数 时间戳 预期发送时间 |
| `expires_millis` | Number | 可选 | 3600000 | 提前过期 相对时间差 毫秒 |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.invalid-message-field: unmatch-topic-meta-info` | 消息content中的字段与系统定义的字段不一致 | 参考消息的定义修改参数 |
| `isv.topic-limitation: pub` | 应用没有发送消息的权限 | 在页面中订阅相应的消息 |
| `isv.ivalid-message-content: error-json-format` | 消息体content的json格式错误 | 修改content为正确的json串 |
| `isv.invalid-param: topic-empty` | topic不能为空 | 输入正确的topic |
