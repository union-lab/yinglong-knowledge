# 权限包 14876 · 卖家地址库管理

| 字段 | 值 |
|---|---|
| **权限包 ID** | `14876` |
| **分类** | 公共场景 |
| **名称** | 卖家地址库管理 |
| **API 数量** | 4 |
| **控制台 API 列表** | [api_list.htm?scopeId=14876](https://open.alitrip.com/docs/api_list.htm?scopeId=14876) |

## 包含接口

#### `taobao.logistics.address.add`

**中文名**：卖家地址库新增接口

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=14876&apiId=10686)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `contact_name` | String | 必须 | 姓名 | 联系人姓名 长度不可超过20个字节 |
| `province` | String | 必须 | 浙江省 | 所在省 |
| `city` | String | 必须 | 杭州市 | 所在市 |
| `country` | String | 可选 | 西湖区 | 区、县 如果所在地区是海外的可以为空，否则为必参 |
| `addr` | String | 必须 | 华星路xx号 | 详细街道地址，不需要重复填写省/市/区 |
| `zip_code` | String | 可选 | 315040 | 地区邮政编码 如果所在地区是海外的可以为空，否则为必参 |
| `phone` | String | 可选 | ****-********-**** | 电话号码,手机与电话必需有一个 |
| `mobile_phone` | String | 可选 | 136******** | 手机号码，手机与电话必需有一个 手机号码不能超过20位 |
| `seller_company` | String | 可选 | 公司名称 | 公司名称, 公司名称长能不能超过20字节 |
| `memo` | String | 可选 | 备注 | 备注, 备注不能超过256字节 |
| `get_def` | Boolean | 可选 | true | 默认取货地址。 选择此项(true)，将当前地址设为默认取货地址，撤消原默认取货地址 |
| `cancel_def` | Boolean | 可选 | true | 默认退货地址。 选择此项(true)，将当前地址设为默认退货地址，撤消原默认退货地址 |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.logistics-address-service-error:P01` | 参数为空或格式不正确 | 对照参数表 |
| `isv.logistics-address-service-error:P03` | 没有用户ID | 检查用户是否登录，或session过期 |
| `isv.logistics-address-service-error:P11` | 参数不符合约定 | 请对照参数表 |
| `isv.logistics-address-service-error:B104` | 已存在相同的地址 | 检查地址库，通过taobao.logistics.address.search接口查询 |
| `isp.logistics-address-service-error:S01` | 系统异常 | 系统异常,联系小二 |

#### `taobao.logistics.address.remove`

**中文名**：删除卖家地址库

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=14876&apiId=10684)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `contact_id` | Number | 必须 | 1231 | 地址库ID |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.logistics-address-service-error:P03` | 没有用户ID | 检查用户是否登录，或session过期 |
| `isv.logistics-address-service-error:P01` | 参数为空 | 检查参数，对照入参表 |
| `isv.logistics-address-service-error:B101` | 地址库信息不存在 | 地址库ID无效，可能通过taobao.logistics.address.search接口获取 |
| `isv.logistics-address-service-error:T08` | 无权操作, | 地址库不属于当前用户 |
| `isv.logistics-address-service-error:B102` | 不能删除默认发货、取货、退货地址 | 先取消默认发货、取货、退货地址后，在进行删除 |
| `isp.logistics-address-service-error:S01` | 系统异常 | 系统异常,联系小二 |

#### `taobao.logistics.address.search`

**中文名**：查询卖家地址库

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=14876&apiId=10683)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `rdef` | String | 可选 | no_def | 可选，参数列表如下： no_def:查询非默认地址 get_def:查询默认取货地址，也即对应卖家后台地址库中发货地址（send_def暂不起作用） cancel_def:查询默认退货地址 缺省此参数时，查询所有当前用户的地址库 |
