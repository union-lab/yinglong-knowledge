## 包含接口

#### `taobao.item.update.delisting`

**中文名**：商品下架

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12165&apiId=31)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `num_iid` | Number | 必须 | 1000231 | 商品数字ID，该参数必须 |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.item-listing-service-error:ITEM_NOT_FOUND` | 没有找到宝贝 | 请求检查商品id是否正确 |
| `isv.invalid-parameter:iid` | 传入的iid错误，不符合基本的格式要求 | 尽快切换到numIid。根据iid规则进行前端校验，如果格式错误就不再调用api |
| `isv.missing-parameter:iid-or-numIid` | 参数：iid或numIid一个都没有传入 | 在前端对是否传入num_iid做好校验，必须传入num_iid |
| `isv.item-listing-service-error:ITEM_IS_NOT_BELONG_TO_SELLER-tmall` | 卖家操作不属于自己的商品 | 请检查商品是否正确 |
| `isp.system-busy` | 调用频率太快 | 减少调用的频率，为了防止滥用，加了限制，请降低频率即可 |
| `isv.item-get-service-error:ITEM_NOT_FOUND` | 没有找到宝贝 | 确认num_iid是否正确 如果num_iid无误，则对应的宝贝可能已违规或进入历史库。 |
| `isv.item-get-service-error:ITEM_NOT_FOUND-tmall` | 商品未找到 | 确认num_iid是否正确，如果num_iid无误，则对应的宝贝可能已违规或进入历史库，在本地增加逻辑：发现报“ITEM_NOT_FOUND”错误就将本地的商品记录删除掉，防止卖家或者系统自动重试再次发生这个问题。 |
| `isv.item-is-delete:invalid-numIid-or-iid` | 根据num_iid或iid查询到的商品一经被删除 | 这个是业务不可避免错误。可以通过一下途径来减少这个问题的发生： 使用增量api监控商品被删除的消息 发生这个错误的商品从本地数据库中删除掉，随时保持数据的同步性。 发生这个错误时不要重试。 |
| `isv.item-listing-service-error:ITEM_NOT_FOUND-tmall` | 商品找不到 | 请检查商品是否正确 |
| `isv.item-not-exist:invalid-numIid-or-iid` | 商品id对应的商品不存在 | 检查商品Id是否正确，或联系开发人员 |
| `isv.missing-parameter:numIid-tmall` | 商品id错误 | 请检查商品是否正确 |
| `isp.top-remote-connection-timeout-tmall` | 系统超时 | 请稍后重试 |
| `isv.item-is-presale:invalid-presale-tags-id-tmall` | 预售商品，修改报错 | 预售商品预售中，不允许修改sku，预售结束后再试试 |
| `isv.item-listing-service-error:IC_PERMISSION_FOR_WT_ONLY-tmall` | 该宝贝只允许网厅平台操作 | 该宝贝只允许网厅平台操作 |
| `isv.item-listing-service-error:IC_INTERFACE_QPS_LIMIT` | 频率限制 | 请控制请求频率 |

#### `taobao.item.update.listing`

**中文名**：一口价商品上架

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12165&apiId=32)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `num_iid` | Number | 必须 | 1000231 | 商品数字ID，该参数必须 |
| `num` | Number | 必须 | 2 | 需要上架的商品的数量。取值范围:大于零的整数。如果商品有sku，则上架数量默认为所有sku数量总和，不可修改。否则商品数量根据设置数量调整为num |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.item-listing-service-error:QUANTITY_ITEM_CAT_TOO_LARGE_OF_ONLINE` | 非特种经营认证卖家发布宝贝数量不能超过数量限制 | 非特种经营认证卖家发布宝贝数量不能超过数量限制 |
| `isv.item-listing-service-error:ERROR_PUBLISH_DUPLICATE` | 宝贝重复发布 | 正常错误提醒，不允许重试。如果报错是商品量的两倍以上，系统会自动报警。 |
| `isv.item-listing-service-error:IC_CHECKSTEP_BEYOND_LOW_PRICE_LIMIT` | 本类目下 价格不得低于${CATEGORY_PRICE_LIMITED_LOW} | 正常错误提醒，请用户按照提醒更改商品价格，不要重试 |
| `isv.item-listing-service-error:IC_CHECKSTEP_ITME_SKU_PRICE_UNMATCH` | 宝贝价格必须介于销售属性组合价格区间之内 | 宝贝价格必须介于销售属性组合价格区间之内 |
| `isv.item-listing-service-error:QUANTITY_TOO_LARGE` | 本类目发布的宝贝数量超出限制，不允许再发布 | 正常错误提醒，不要重试 |
| `isv.item-listing-service-error:REST_TOTAL_QUANTITY_GREAT_10` | 闲置宝贝累计发布数量不得大于10件 | 闲置宝贝累计发布数量不得大于10件 |
| `isv.item-listing-service-error:CATEGORY_IS_NOT_LEAF_OR_NOT_EXIST` | 选择的类目不存在或者类目路径不完整 | 选择的类目不存在或者类目路径不完整 |
| `isv.item-listing-service-error:ERROR_PUBLISH_PERMISSION_INVALID_FOR_FRANCHISE` | 您没有特种类目的经营权限，请核实 | 您没有特种类目的经营权限，请核实 |
| `isv.item-listing-service-error:ERROR_AUTO_SAME` | 卡密信息出错，请确认卡密格式等无误 | 卡密信息出错，请确认卡密格式等无误 |
| `isv.missing-parameter:iid-or-numIid` | 参数：iid或numIid没有传入 | 必须传入num_iid |
| `isv.item-listing-service-error:IC_BRAND_NOT_GRANT_FOR_B` | 未授权发布此品牌的商品 | 用taobao.itemcats.authorize.get接口确认被授权发布的品牌，再发布该品牌的商品 |
| `isv.item-listing-service-error:IC_CHECKSTEP_NO_PERMISSION` | 您未通过认证或已被处罚，请核实 | 一旦发生该错误，就要将该用户做上标记，让用户去检查自己的权限问题，等用户处理好了让用户来手动取消禁止标记，发生该错误不要重试 |
| `isv.item-listing-service-error:REST_QUANTITY_GREAT_1` | 闲置宝贝每次只能发布1件 | 闲置宝贝每次只能发布1件 |
| `isv.item-listing-service-error:IC_ITEM_MUST_IMAGE` | 请添加 宝贝图片 | 请添加 宝贝图片 |
| `isv.item-listing-service-error:QUANTITY_TOO_LARGE_FOR_SECOND_HAND` | 该类目下二手宝贝只能发布1件 | 该类目下二手宝贝只能发布1件 |
