## 包含接口

#### `taobao.trade.memo.add`

**中文名**：对一笔交易添加备注

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12147&apiId=48)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `tid` | Number | 必须 | 123456789 | 交易编号 |
| `memo` | String | 必须 | 交易备注 | 交易备注。最大长度: 1000个字节 |
| `flag` | Number | 可选 | 1 | 交易备注旗帜，可选值为：0(灰色), 1(红色), 2(黄色), 3(绿色), 4(蓝色), 5(紫色), 6(橙色), 7(浅蓝), 8(浅粉), 9(深绿), 10(桃红), 默认值为0 |
| `tag` | String | 可选 | 红色旗子 | 插旗备注 |
| `operator` | Number | 可选 | 123456 | 操作者 |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.trade-not-exist` | trade 不存在 |  |
| `isv.invalid-parameter` | 参数无效，格式不对、非法值、越界等 |  |
| `isv.invalid-permission` | 必须是此交易的卖家或买家才能添加交易备注 | 查看是否程序出问导致添加交易备注的交易不属于该卖家，出现错误不要重试 |

#### `taobao.trade.memo.update`

**中文名**：修改交易备注

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12147&apiId=49)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `tid` | Number | 必须 | 123456789 | 交易编号 |
| `memo` | String | 可选 | 交易备注 | 卖家交易备注。最大长度: 1000个字节 |
| `flag` | Number | 可选 | 1 | 交易备注旗帜，可选值为：0(灰色), 1(红色), 2(黄色), 3(绿色), 4(蓝色), 5(紫色), 6(橙色), 7(浅蓝), 8(浅粉), 9(深绿), 10(桃红), 默认值为0 |
| `reset` | Boolean | 可选 | true | 是否对memo的值置空若为true，则不管传入的memo字段的值是否为空，都将会对已有的memo值清空，慎用；若用false，则会根据memo是否为空来修改memo的值：若memo为空则忽略对已有memo字段的修改，若memo非空，则使用新传入的memo覆盖已有的memo的值 |
| `tag` | String | 可选 | 红色旗子 | 旗子备注 |
| `operator` | Number | 可选 | 123456 | 操作者 |
| `clear_tag` | Boolean | 可选 | true | 是否对旗子自身tag和订单快照tag的值置空。若为true，则不管传入的tag字段的值是否为空，都将会对已有的旗子本身tag和订单快照tag值清空，慎用；若用false，则会根据tag是否为空来修改tag的值：若tag为空则忽略对已有tag字段的修改，若tag非空，则使用新传入的tag覆盖已有的旗子本身tag和订单快照tag的值 |

**常见错误码**

| 错误码 | 描述 | 解决方案 |
|---|---|---|
| `isv.invalid-permission` | 权限不够、非法访问 |  |
| `isv.trade-not-exist` | 交易不存在 | 传人正确的订单号 |
| `isv.invalid-parameter:memo` | 备注错误 | 备注错误，一般是备注格式太长，根据api文档该字段要求，重新入参 |
| `isp.trade-service-failed` | 交易接口服务错误 | 交易接口服务错误，稍后重试 |

#### `taobao.trade.shippingaddress.update`

**中文名**：更改交易的收货地址

**官方文档**：[链接](https://open.alitrip.com/docs/api.htm?scopeId=12147&apiId=241)

**请求参数（业务参数，已排除公共参数）**

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|:---:|---|---|
| `tid` | Number | 必须 | 123456789 | 交易编号。 |
| `receiver_name` | String | 可选 | 张三 | 收货人全名。最大长度为50个字节。 |
| `receiver_phone` | String | 可选 | 0571-12345678 | 座机号码。最大长度为30个字节。传-1表示删除 |
| `receiver_mobile` | String | 可选 | 13600000000 | 移动电话。最大长度为11个字节。传-1表示删除 |
| `receiver_state` | String | 可选 | 浙江 | 省份。最大长度为32个字节。如：浙江 |
| `receiver_city` | String | 可选 | 杭州 | 城市。最大长度为32个字节。如：杭州 |
| `receiver_district` | String | 可选 | 西湖区 | 区/县。最大长度为32个字节。如：西湖区 |
| `receiver_address` | String | 可选 | xx路xx号 | 收货地址。最大长度为228个字节。 |
| `receiver_zip` | String | 可选 | 310001 | 邮政编码。必须由6个数字组成。注：邮政编码根据地址信息自动填入，不可单独修改 |
| `receiver_town` | String | 可选 | 五常街道 | 四级地址。最大长度为32个字节。如：五常街道 |

| `isv.invalid-parameter:tid` | 交易不属于当前用户：*** | 查看是否程序出问导致取到别的卖家的交易而无法更新地址，出现错误不要重试 |
| `isv.invalid-parameter:receiver_address` | 无效的地址 | 参数重新设置 |
| `isv.invalid-parameter:receiver_zip` | 无效的邮编 | 参数重新设置 |
| `isv.invalid-parameter:receiver_mobile` | 无效的手机号 | 参数重新设置 |
| `isv.invalid-parameter:receiver_phone` | 无效的电话 | 参数重新设置 |
| `isv.invalid-parameter:receiver_name` | 无效的收货人名称 | 参数重新设置 |
| `isv.invalid-parameter:receiver_district` | 无效的区 | 参数重新设置 |
| `isv.invalid-parameter:receiver_city` | 无效的市 | 参数重新设置 |
| `isv.invalid-parameter:receiver_state` | 无效的省 | 参数重新设置 |
| `isp.trade-service-failed` | 接口服务错误 | 接口服务错误，稍后重试 |
| `isp.modify-address-failed` | 改地址系统更新订单错误 | 无 |

**中文名**：修改交易邮费价格

| 参数 | 类型 | 必填 | 示例 | 说明 |

| `isv.trade-service-error` | 调用修改订单费用服务异常 | 调用修改订单费用服务异常，稍后重试 |
