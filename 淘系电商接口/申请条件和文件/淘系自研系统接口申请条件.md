## 6. 聚石塔入驻方案与费用分析

> **复核说明**：[聚石塔概述（docId=101130）](https://open.taobao.com/doc.htm?docId=101130&docType=1) 仅介绍平台特性；**入驻要求与费用口径**以 [自研电商后台系统开发指引](https://open.alitrip.com/docs/doc.htm?articleId=118848&docType=1&treeId=796) §五/§七、[聚石塔规则](https://open.alitrip.com/docs/doc.htm?articleId=101896&docType=1&treeId=796)、[API 技术服务费（docId=104559）](https://open.taobao.com/doc.htm?docId=104559&docType=1) 为准。  
> **分析日期**：2026-06-26 · **适用场景**：友联医疗器械专营店 + 同主体可能扩多店

### 6.1 聚石塔是什么、为什么必须入塔

聚石塔是淘宝开放平台联合阿里云提供的**电商云工作平台**，面向 ISV 与**商家自研系统**。[商家后台系统](https://jaq-doc.alibaba.com/docs/doc.htm?treeId=20&articleId=101564&docType=1) 类应用**必须**将接口代码部署在聚石塔内。

| 规则 | 说明 |
|------|------|
| **入塔范围** | 「商家后台系统」等 23 类应用标签**必须入驻聚石塔**（见聚石塔规则） |
| **API 调用位置** | **涉及订单数据的 API 必须在塔内发起**，禁止在自有服务器（如 Railway）外调 |
| **数据存储** | 淘宝店铺相关订单数据须存放在**聚石塔 RDS**；数据库不得安装在 ECS 上 |
| **账号绑定** | 购买聚石塔 ECS/RDS 的淘宝账号 **= 创建应用的淘宝账号**（`youlianzhuanying@163.com`），平台校验绑定关系 |
| **无固定入驻费** | 聚石塔**不收**单独「入驻费」；实际支出为**云资源 + API 按量费**（可选订单推送费） |

官方建议机器配置（约 20 次/秒请求量）：**1～2 台 4核8G ECS** + RDS；大促可弹性扩容。

### 6.2 友联推荐入驻方案：塔内连接器（最小合规）

不建议将 union-dashboard / union-agent **整站搬迁**至聚石塔。按官方指引，前期可**只把淘系订单处理与 API 调用代码**部署在塔内，主系统仍在塔外，通过**奇门**做受控数据互通。

```
┌─────────────────────────────────────────────────────────────┐
│  聚石塔内（必须）                                              │
│  ┌──────────────┐    ┌──────────────┐                       │
│  │ ECS：淘宝连接器 │───▶│ RDS：订单库   │                       │
│  │ · OAuth/token  │    │ · 订单快照    │                       │
│  │ · 订单拉取/推送  │    │ · 状态变更    │                       │
│  │ · 发货回传      │    └──────────────┘                       │
│  └──────┬───────┘                                           │
└─────────┼───────────────────────────────────────────────────┘
          │ 奇门（非敏感业务字段 / 受控出塔）
          ▼
┌─────────────────────────────────────────────────────────────┐
│  塔外（友联现有架构）                                          │
│  union-agent · union-dashboard · Railway PG 数仓              │
│  旺店通 · 金蝶 · RPA 替代链路                                  │
└─────────────────────────────────────────────────────────────┘
```

| 组件 | 部署位置 | 职责 |
|------|---------|------|
| **淘宝连接器微服务** | 聚石塔 ECS | 塔内调用 TOP API；订单审核/发货回传；token 刷新 |
| **订单 RDS** | 聚石塔 RDS | 存淘系订单及状态；可开通订单推送写入 |
| **union-dashboard** | 塔外（现有） | 运营界面；审核/发货操作可通过 API 调塔内服务或奇门 |
| **数仓 / 金蝶 / 旺店通** | 塔外 | 非订单敏感数据同步；**敏感收件人信息不得随意出塔** |

**方案对比：**

| 方案 | 说明 | 月云成本粗算 | 推荐 |
|------|------|-------------|------|
| **A 塔内连接器（推荐）** | 仅连接器 + 小 ECS + 小 RDS | **350～550 元/月** | ✅ 首期 |
| **B 标准入塔** | 1×4C8G ECS + RDS，订单模块全在塔内 | **450～700 元/月** | 审核通过后扩展 |
| **C 整站迁移** | Dashboard + Agent 全部上聚石塔 | **800～1,500 元/月** | ❌ 非必要 |

产品说明书 §4.1 架构图建议**同时画清塔内/塔外边界**，便于聚石塔架构审核。

### 6.5 友联费用估算

**假设**：友联医疗器械专营店单店，日均 **100～300 单**；每单约 **3～5 次** API（查单、详情、发货等）。

#### 云资源（持续支出，最大头）

| 组件 | 建议规格 | 月费估算 | 年付参考 |
|------|---------|---------|---------|
| ECS × 1 | 4核8G | 130～350 元/月 | 包年约 800～1,000 元/年 |
| RDS MySQL | 基础版 1～2核、50～100GB | 100～300 元/月 | 新人套餐有时 ~200～300 元/年 起 |
| Redis（可选） | 大促再加 | 0～150 元/月 | — |
| 带宽 / 磁盘 | 按控制台选配 | 20～80 元/月 | — |

**云资源合计（方案 A）**：约 **250～700 元/月**，取中位 **400～500 元/月**。

#### API 调用费（按量，单店通常很低）

| 测算 | 数值 |
|------|------|
| 日调用量 | 300～1,500 次 |
| 月调用量 | 约 1～4.5 万次 |
| 月 API 费（塔内基础 API） | **约 2～10 元/月** |

多店同步放大，一般仍 **< 100 元/月**。

#### 订单推送（若开通）

| 测算 | 数值 |
|------|------|
| 日订单 | 100～300 单 |
| 月推送费（0.12 元/百单） | **约 4～11 元/月** |

远低于日套餐 79 元起门槛。

| 场景 | 首年估算 | 稳态月费 |

### 8.2 §1 概述

**1.1 名词解释（必填，应用名称必须解释）**

| 系统/名词 | 说明（示例，提交前需定稿） |
|----------|--------------------------|
| **友联供应链 ERP 管理系统** | 友联自研 OMS/ERP，用于淘系等多渠道电商的订单、商品、库存、发货一体化管理 |
| **union-dashboard** | 系统 Web 管理端，运营与仓储人员操作界面 |
| **union-agent** | 系统后端服务，负责 API 对接、数据同步与业务逻辑 |
| **OMS** | Order Management System，订单管理系统 |
| **ERP** | Enterprise Resource Planning，企业资源计划（含进销存） |

**1.2 产品概述及目标（必填，须含业务场景与解决什么问题）**

| 要点 | 友联表述方向 |
|------|-------------|
| **业务场景** | 友联医疗器械专营店及同主体淘系店铺，日订单量大，需与金蝶 ERP、旺店通、自研数仓打通 |
| **核心痛点** | 订单靠人工导出/RPA 抓取；发货需在多系统间切换；财务账单与订单对账效率低 |
| **建设目标** | 通过淘系开放平台 API 实现订单自动拉取、审核、发货回传、商品与账单同步 |
| **预期收益** | 减少人工操作、缩短发货时效、账单数据入仓替代 RPA |

## 12. 工单问答归档

### Q1：软著是否必须含 ERP 或 Order 等关键词？

**A：必须含 `OMS` 或 `ERP`。** 「Order」 alone 未被平台明确认可，以工单答复为准。

### Q2：订单管理模块能否作为供应链/采购大系统的一部分？

**A：可以。** 平台关注系统整体定位为 OMS/ERP，且具备订单审核、订单发货能力；不要求订单模块单独拆成独立软著，但**软著名称仍须含 OMS/ERP**。

### Q3：除技术团队与系统功能外，还有哪些要求？

**A：** 企业开发者资质、合规软著、应用类型选进销存/ERP、聚石塔部署、可访问的演示环境与测试账号。

### Q4：一个申请能否覆盖多店铺？

**A：可以。** 同一商家一次申请即可。

### Q5：软著可以更改软件名称吗？

**A：可以。** 未下证直接改名称重新提交；已下证走「软件登记事项变更登记」。变更不涉及功能性能变化，版本号一般仅限加/去 `V`。
