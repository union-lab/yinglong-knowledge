# 京东秒送客服类工具软件服务商申请

> 客服类工具作为独立产品和独立申请对象整理，不并入全链路ERP或订单管理申请成本。

## 已明确事项

- 京东秒送客服类工具可以申请软件服务商资质。
- 该结论由用户于2026-07-27确认。
- 具体申请入口、平台正式类目名称、账号隔离和保证金规则仍需取得官方材料佐证。

## 一、能力范围

京东秒送客服管理工具主要包括：

- 客服工单管理
- 售后单管理
- 客服机器人对话
- 客服绩效管理
- 客服服务效率和质量提升

客服能力可以作为全链路ERP中的一个模块，但以独立客服工具对外提供服务时，应按客服类工具单独准备产品、案例、团队和申请材料。

## 二、当前已知准入条件

| 维度 | 京东官方公开要求 |
|---|---|
| 企业年限 | 成立1年以上 |
| 注册资本 | 大于100万元 |
| 企业性质 | 独立法人 |
| 办公场所 | 至少1个办公场所租赁合同及办公场景照片或视频 |
| 等级保护 | 对接业务系统需取得公安部信息系统安全等级保护二级及以上证明 |
| Web安全 | 购买并使用系统所在云服务器的Web应用防火墙 |
| 产品经验 | 具备线上电商或秒送智能客服、客服绩效场景经验 |
| 客户案例 | 不少于3个品牌客户运营服务案例 |
| 产品材料 | 提供完整MRD和PRD |
| 企业规模 | 不低于40人 |
| 技术团队 | 不少于20人 |
| 运营服务 | 具备一定规模的运营和服务团队 |

## 三、费用口径

| 费用项 | 当前已知 |
|---|---:|
| 京东服务市场保证金 | 50,000元 |
| 运营支持服务费 | 0% |
| 等保二级 | 待取得正式报价 |
| Web应用防火墙 | 待取得正式报价 |
| 客服机器人或大模型调用费 | 待按产品方案测算 |
| 消息、工单和会话存储 | 待按数据量测算 |
| 在线客服及售后人员 | 待按服务时段和SLA测算 |

## 四、申请材料重点

1. 客服工具MRD。
2. 客服工具PRD。
3. 客服工单、售后、机器人及人工转接流程。
4. 等保二级及以上证明。
5. Web应用防火墙购买及使用证明。
6. 不少于3个品牌客户案例。
7. 企业和技术团队人员证明。
8. 客服值班、投诉、故障和数据安全制度。
9. 客服机器人知识库、质检及人工兜底方案。
10. 客服数据访问、脱敏、留存和删除规则。

## 五、持续运营重点

1. 客服系统需要保持稳定可用，并建立监控和告警。
2. 客服、售后和用户数据可能涉及敏感信息，需要执行权限隔离和脱敏。
3. 机器人回复必须设置人工兜底和异常升级机制。
4. 需明确工作时间、响应时效、投诉处理和故障应急机制。
5. 京东服务商店铺上线后仍需保持京麦或咚咚客服在线，该义务与所开发的客服工具不是同一事项，应分别核算人员成本。

## 六、待确认

1. 秒送客服管理在申请页面中的正式类目名称和申请入口。
2. 客服机器人、客服绩效、客服工单是否需要分别申请。
3. 客服类工具是否需要额外的算法备案、生成式AI备案或内容安全审核。
4. 客服工具能否与全链路ERP共用APPKEY和基础设施。
5. 独立客服工具是否必须使用独立企业账号。
6. 独立客服工具是否需要另缴一笔5万元保证金。
7. 客服会话、工单和售后数据允许保存的期限及部署位置。
