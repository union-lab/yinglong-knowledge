# 京东秒送订单管理软件服务商申请

> 京东秒送招商页面对应名称为“交易履约”。本文件按友联业务理解称为“订单管理”，与全链路ERP申请独立整理。

## 一、能力范围

订单管理工具主要提供：

- 订单接收和订单管理
- 订单处理
- 打印面单或小票
- 订单数据分析
- 售后单管理
- 订单履约相关操作

该类工具以订单和履约场景为核心，不要求天然覆盖商品、门店、营销、会员和客服等完整ERP模块。

## 二、当前已知准入条件

| 维度 | 京东官方公开要求 |
|---|---|
| 企业年限 | 成立1年以上 |
| 注册资本 | 大于100万元 |
| 企业性质 | 独立法人 |
| 办公场所 | 至少1个办公场所租赁合同及办公场景照片或视频 |
| 等级保护 | 对接业务系统需取得公安部信息系统安全等级保护二级及以上证明 |
| Web安全 | 购买并使用系统所在云服务器的Web应用防火墙 |
| 产品经验 | 具备线上电商或秒送订单履约、打印场景的产品经验和能力 |
| 客户案例 | 不少于2个品牌客户成功服务案例 |
| 产品材料 | 提供完整MRD和PRD |
| 企业规模 | 不低于30人 |
| 技术团队 | 不少于10人 |
| 运营服务 | 具备一定规模的运营和服务团队 |

## 三、与全链路ERP的区分

| 对比项 | 全链路ERP | 订单管理 |
|---|---|---|
| 官方名称 | 全链路解决方案 | 交易履约 |
| 核心范围 | 商品、门店、订单、履约、营销、会员、客服 | 订单、打印、履约、售后 |
| 企业年限 | 2年以上 | 1年以上 |
| 注册资本 | 大于500万元 | 大于100万元 |
| 企业规模 | 不低于50人 | 不低于30人 |
| 技术团队 | 不少于20人 | 不少于10人 |
| 客户案例 | 5个以上，含1个详细标杆案例 | 不少于2个品牌案例 |
| ERP软件著作权 | 明确要求 | 待确认 |
| ISO27001等认证 | 明确列入相关资料 | 待确认 |

## 四、费用口径

| 费用项 | 当前已知 |
|---|---:|
| 京东服务市场保证金 | 50,000元 |
| 运营支持服务费 | 0% |
| 等保二级 | 待取得正式报价 |
| Web应用防火墙 | 待取得正式报价 |
| 订单打印硬件及适配 | 待确定支持设备范围后测算 |
| 服务器、数据库和监控 | 待京东确认部署要求后测算 |

## 五、申请材料重点

1. 订单管理产品MRD。
2. 订单管理产品PRD。
3. 订单接收、处理、打印、履约及售后流程图。
4. 等保二级及以上证明。
5. Web应用防火墙购买及使用证明。
6. 不少于2个品牌客户案例。
7. 企业和技术团队人员证明。
8. 打印机、面单、小票等硬件兼容清单。
9. 系统监控、消息补偿、订单防重和应急预案。

## 六、待确认

1. 资费表中的“订单工具”“打单发货”与招商页面“交易履约”的准确类目映射。
2. 订单管理类目是否开放招商或需要邀约。
3. 软件著作权是否为强制材料。
4. 是否必须兼容指定打印机、POS机或小票设备。
5. 申请订单管理后能否同时申请全链路ERP。
6. 两个申请是否共用一笔保证金。
7. 两个申请是否必须使用独立企业账号。
