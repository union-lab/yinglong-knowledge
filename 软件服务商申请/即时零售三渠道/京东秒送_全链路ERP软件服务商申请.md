# 京东秒送全链路ERP软件服务商申请

> 京东官方页面对应名称为“全链路解决方案”。本文件按友联内部理解称为“全链路ERP”，与订单管理单项工具分别核算和申请。

## 一、能力范围

面向京东秒送的外卖、到店及即时零售商家，提供包括以下模块在内的全链路解决方案：

- 店铺及门店管理
- 商品管理
- 订单与收银
- 配送履约
- 营销与会员
- 客服管理
- 品牌总部到门店的经营管理

该申请目标强调多模块一体化和行业解决方案能力，不等同于仅处理订单、打印、售后单的订单管理工具。

## 二、当前已知准入条件

| 维度 | 京东官方公开要求 |
|---|---|
| 企业年限 | 成立2年以上 |
| 注册资本 | 大于500万元 |
| 企业性质 | 独立法人 |
| 办公场所 | 至少1个办公场所租赁合同及办公场景照片或视频 |
| 等级保护 | 对接业务系统需取得公安部信息系统安全等级保护二级及以上证明 |
| 软件能力 | 具备ERP系统相关应用开发经验 |
| 知识产权 | 提供ERP类软件著作权 |
| 安全体系 | 提供ISO27000或ISO27001等体系认证材料 |
| Web安全 | 购买并使用系统所在云服务器的Web应用防火墙 |
| 产品材料 | 提供完整MRD和PRD |
| 行业经验 | 具备餐饮或即时零售商品、门店、交易、履约等领域的产品能力 |
| 客户案例 | 5个以上成功服务案例，其中至少1个标杆客户详细实施案例 |
| 企业规模 | 不低于50人 |
| 技术团队 | 不少于20人 |
| 运营服务 | 具备一定规模的运营和服务团队 |

## 三、费用口径

| 费用项 | 当前已知 |
|---|---:|
| 京东服务市场保证金 | 50,000元 |
| 运营支持服务费 | 0% |
| 等保二级 | 待取得正式报价 |
| Web应用防火墙 | 待取得正式报价 |
| ISO27001等体系认证 | 待确认现有证书及补充成本 |
| 软件著作权 | 待确认现有证书能否覆盖 |
| 服务器、数据库及监控 | 待京东确认部署要求后测算 |

## 四、申请材料重点

1. 全链路ERP产品MRD。
2. 全链路ERP产品PRD。
3. 系统架构图和数据流转图。
4. ERP软件著作权。
5. 等保二级及以上证明。
6. ISO27000或ISO27001等体系认证。
7. Web应用防火墙购买及使用证明。
8. 5个以上即时零售或餐饮客户案例。
9. 至少1个标杆客户详细实施案例。
10. 企业及技术团队人员证明。
11. 中长期研发、销售、运营和服务计划。

## 五、待确认

1. 全链路解决方案是否属于定向邀约。
2. 友联现有ERP功能是否达到“全链路”审核口径。
3. 全链路ERP是否必须同时具备商品、订单、履约、会员和客服全部模块。
4. ISO27001是否为强制要求，还是可由同等安全认证替代。
5. 申请全链路ERP后，是否仍需另行申请订单管理和客服类工具资质。
6. 同一企业不同软件类目是否需要使用独立企业账号。
