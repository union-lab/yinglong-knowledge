## 状态登记规则

- “当前阶段”记录申请所在环节，例如：材料准备、已提交、平台审核、补正、缴纳保证金、应用上线审核、已完成。
- “当前状态”记录该环节的实际结果，避免把“进入缴费页面”误记为“已缴费”。
- 每次更新均记录日期、平台反馈和相关截图或文件证据。
